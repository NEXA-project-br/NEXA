# Definição do Tema – Sistema Financeiro Pessoal

##  Qual será o software a ser desenvolvido?

O software a ser desenvolvido será um **Sistema Financeiro Pessoal Desktop**, criado em Java, com funcionamento **100% offline**.

O objetivo do sistema é permitir que usuários controlem suas finanças de forma simples, organizada e segura.

###  Funcionalidades principais:

* Cadastro de receitas

* Cadastro de despesas

* Cadastro e gerenciamento de categorias (Alimentação, Lazer, Transporte etc.)

* Cálculo automático do saldo (Saldo \= Receitas – Despesas)

* Filtro por período (data inicial e final)

* Relatórios financeiros simples

* Armazenamento local dos dados

O sistema seguirá uma organização estruturada para garantir clareza, manutenção e qualidade do código.

---

## Onde será implantado?

O sistema será implantado em **computadores pessoais (Desktop)**, podendo funcionar em:

* Windows

* Linux

* MacOS

Desde que o usuário possua o **Java Runtime Environment (JRE)** instalado.

O sistema funcionará totalmente offline, armazenando os dados localmente na máquina do usuário, garantindo maior privacidade.

---

## Quem são os usuários?

O público-alvo do sistema são:

* Pessoas que desejam organizar suas finanças pessoais

* Estudantes

* Trabalhadores autônomos

* Pequenos empreendedores

* Usuários que preferem soluções offline por segurança e privacidade

O sistema é ideal para quem busca simplicidade e controle financeiro sem depender de aplicativos conectados à internet.

---

## Quem são os concorrentes?

Alguns concorrentes diretos e indiretos incluem:

* **Mobills** – Aplicativo de controle financeiro com versão online.

* **Guiabolso** – Plataforma integrada com bancos.

* **Organizze** – Sistema de organização financeira online.

### Diferencial do projeto:

* Funcionamento totalmente offline

* Foco em privacidade dos dados

* Simplicidade de uso

* Baixo custo
