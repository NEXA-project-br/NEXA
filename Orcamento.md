## 2️⃣ Arquitetura do Sistema

### 📌 Tipo de Sistema
Aplicação **Desktop Offline**, desenvolvida em **Java**, com armazenamento local.

### 🏗️ Arquitetura Técnica

**Padrão arquitetural:**  
- MVC (Model-View-Controller)

**Tecnologias utilizadas:**
- Java SE 17+
- Swing ou JavaFX (Interface gráfica)
- SQLite (banco de dados embarcado)
- JRE (Java Runtime Environment)

### 💾 Implantação

O sistema será instalado diretamente no computador pessoal da cliente.

**Compatível com:**
- Windows  
- Linux
- MacOs

> Requisito: possuir o Java Runtime Environment (JRE) instalado.

### 🔐 Privacidade e Segurança

- Funcionamento 100% offline  
- Nenhum envio de dados para servidores externos  
- Dados armazenados exclusivamente no computador da usuária  
- Backup sob responsabilidade da cliente  

---

## 3️⃣ Esboços de Telas e Funcionalidades

### 🏠 Tela Principal (Dashboard)

**Exibe:**
- Saldo atual (Receitas – Despesas)
- Total de receitas do período
- Total de despesas do período

**Botões principais:**
- Nova Receita
- Nova Despesa
- Categorias
- Relatórios
- Filtro por período

---

### 💰 Tela de Cadastro de Receitas

**Campos:**
- Descrição
- Valor
- Data
- Categoria

**Validações:**
- Valor obrigatório
- Data válida
- Categoria previamente cadastrada

---

### 💸 Tela de Cadastro de Despesas

**Campos:**
- Descrição
- Valor
- Data
- Categoria

**Validações:**
- Impedir campos vazios
- Impedir valor negativo

---

### 🗂️ Tela de Categorias

**Funcionalidades:**
- Criar categoria
- Editar categoria
- Excluir categoria

**Exemplos de categorias:**
- Alimentação
- Transporte
- Moradia
- Lazer
- Saúde

---

### 📊 Tela de Relatórios

Permite:
- Filtrar por período (data inicial e final)
- Visualizar:
  - Total de receitas
  - Total de despesas
  - Saldo final
- Relatório em formato de tabela
